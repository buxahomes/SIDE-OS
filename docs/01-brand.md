# 品牌与服务

状态：依据现行报价原图、SOP V1.2及本次可见对话整理。来源见 sources/manifest.json。

- 名称：SIDE 一程。
- 面向客户的名称：城市同行服务；报价和推广文案回避“地陪”。
- 当前测试范围：北京、沈阳，人工闭环运营。不是已经验证全国交付能力。
- 核心：经过匹配、准备和运营保障的一段城市时光；运营持续负责订单。
- 当前报价图标语：让一段同行，成为值得记住的城市时光。
- 表达：健康、公开、有边界的城市同行。认真回应、照顾节奏，避免承诺心动或感情结果。

## 对客与内部信息

报价图保留客户需要的金额、起订、包天优惠及费用说明。不要显示“测试阶段暂不分等级，所有Side统一价格”这一内部解释。历史新星、闪耀、星选等级只作旧版记录，当前不据此计价。

候选人资料采集与客户展示分开：内部核对真实信息及接单条件；对客展示相处体验、适配场景、基础资料和必要边界，不照搬内部表单。
