## 核心目标

在保留人物辨识度与照片吸引力的前提下，减少僵硬摆拍、过度精修和不合理环境带来的人工感。重点是人物正在经历一个具体瞬间，光线、动作、材质和空间相互符合。真实感不等于环境脏旧，也不等于照片低清。

## 1. 有原因的不完美

每张优先选择 2—3 项轻微变化，不把所有瑕疵堆到同一张照片上。

| 维度 | 默认做法 | 控制边界 |
| --- | --- | --- |
| 皮肤 | 自然细微毛孔、肤色变化、符合光源的小面积油光；保留参考中的纹理 | 不凭空添加痣、疤痕、雀斑、痘痘或明显皱纹；不改变年龄和本人特征 |
| 机位 | 同行者视角、轻微倾斜、略偏中心、自然裁切；按场景选择拍摄距离与高低 | 不用极端角度扭曲脸型、头身比例；客户应能看清长相 |
| 成像 | 暗部轻微噪点、窗外局部高光溢出、运动手指轻微软化、轻微白平衡偏差 | 不全图模糊、不叠厚重颗粒；保持脸部清晰可辨；不过度虚化背景 |
| 情绪表情 | 听到呼唤刚转头、开口回应、笑到一半、短暂停顿思考 | 表情必须由场景触发；避免每张都直视镜头或保持同款标准微笑 |
| 头发妆容 | 风吹散的几根发丝、帽衫摩擦后的发梢、少量自然凌乱 | 依据人物造型选择；不默认给人物添加妆容或污损 |
| 服饰 | 肘部压褶、抬臂产生的拉伸、背包肩带压痕、略歪领口、不同高度的卷袖 | 褶皱随动作与受力形成；不默认增加污点、破损或暴露 |

用户提供的瑕疵词属于可选素材，不是每次必须逐项使用的清单。

## 2. 五个维度写清具体细节

1. 光线：明确主光源方向、是否混合室内灯光、脸部与背景的明暗关系；反射和阴影应符合物理关系。
2. 材质：写明皮肤、棉布、牛仔、玻璃、金属等如何反光、受压和起褶；避免所有表面都一样光滑。
3. 构图：明确是谁拍、站或坐在哪里、相距多远、用什么机位；构图略有偶然性但不影响辨识。
4. 情绪：给表情一个触发原因，例如同行者说了一句话；允许自然不对称和过渡状态。
5. 动作：选择动作开始或结束前的一瞬间，手、身体重心、衣服及配件形成连贯关系。

环境应是可正常使用的空间：车门接缝、扶手、桌椅和窗框位置合理；窗户反射与光源一致；近处运动景物与远景模糊程度有差别。保持自然生活物件即可，不为去 AI 感刻意堆砌污渍、损坏和杂物。

## 3. 有情境依据的随机变化

每张加入 1—2 个相容的随机状态或形容词，例如「刚坐下」「略微分神」「被叫住」「轻松回应」「发梢被风吹散」。先写事件，再由事件推导表情、动作和成像变化。

不随机改变人物身份、五官、身材和永久特征；不叠加互相矛盾的情绪、天气、光线和动作。同一场景成组照片保持服装、季节、地点与时间逻辑一致，变化拍摄距离、动作和神态。

## 4. 镜头与光学缺陷词（模拟真实摄影）

### 光圈与对焦

| 提示词 | 中文含义与使用说明 |
| --- | --- |
| `chromatic aberration` | 色差；可在少量高反差边缘加入轻微色彩偏移 |
| `lens flare` | 镜头眩光；由画面内或画外强光源触发，注意光源方向 |
| `halation` | 高光周围的光晕或泛光；原提案称「晕影」，执行时区别于画面四角变暗的暗角效果 |
| `soft focus on edges` | 边缘柔焦；主体脸部仍保持清晰可辨 |
| `motion blur` | 轻微动态模糊；用于运动中的手、衣摆或背景，方向应与运动一致 |
| `depth of field` | 景深；按前后距离安排清晰与虚化层次，避免随机模糊或抠图式虚化 |

### 噪点与画质

| 提示词 | 中文含义与使用说明 |
| --- | --- |
| `film grain` | 胶片颗粒感；选择胶片质感时少量使用 |
| `analog noise` | 模拟噪点；与所选成像介质和画面亮度相容 |
| `ISO 1600` | 高感设置提示；可用于弱光环境的噪点倾向，不代表实际拍摄参数 |
| `dust scratches` | 灰尘与划痕；用于胶片扫描或旧照片效果，普通手机照片不默认添加 |

## 5. 光影与色彩瑕疵词（打破过度均质）

### 光影不完美

| 提示词 | 中文含义与使用说明 |
| --- | --- |
| `harsh direct sunlight` | 生硬直射光；允许明确的硬阴影和局部眯眼反应 |
| `mixed lighting` | 杂色混合光；如窗外日光与室内暖灯并存，写清各自方向和影响范围 |
| `underexposed shadows` | 暗部欠曝、局部细节丢失；不让整张脸陷入无法辨认的阴影 |
| `overexposed highlights` | 高光过曝或溢出；优先用于窗外、灯具或反光表面的局部 |
| `color fringing` | 紫边或彩边；与色差效果相近，通常二选一，避免重复强化 |

### 色彩风格

| 提示词 | 中文含义与使用说明 |
| --- | --- |
| `faded colors` | 轻微褪色；按本次风格需要选用 |
| `Fujifilm Superia color grading` | 富士胶片色彩倾向；作为整组可选色彩方向 |
| `CineStill 800T` | 电影胶片色调参考；可用于相容的夜景或人工灯光场景 |
| `imperfect color balance` | 色彩平衡不完美；允许轻微白平衡偏差，保留人物正常肤色辨识度 |

胶片色调和褪色属于可选风格，不是去 AI 感的必选项。同一组优先选择一种摄影介质和色彩方向；不默认同时叠加 Superia 与 CineStill 两种色调。用户要求不使用「氛围1」时，继续以该场景自身的光色为准。

## 6. 材质与细节杂乱词（打破塑料平滑感）

### 皮肤与主体

| 提示词 | 中文含义与使用说明 |
| --- | --- |
| `skin pores` | 真实毛孔；符合拍摄距离与分辨率，不做夸张的全脸纹理 |
| `vellus hair` | 细小汗毛；近景或侧光下可有轻微可见细节 |
| `asymmetry` | 自然不对称；保留参考本人的差异及瞬间表情，不人为扭曲五官 |
| `wrinkled clothing` | 起皱的衣服；褶皱跟随动作、受压位置与布料材质 |
| `minor blemishes` | 微小瑕疵；优先保留真人参考中已有的细节，不凭空添加痣、疤痕、痘痘等身份特征 |

### 环境与杂物

| 提示词 | 中文含义与使用说明 |
| --- | --- |
| `cluttered background` | 杂乱的背景；采用符合场所用途的生活物件，数量适度、位置合理 |
| `random dust particles in the air` | 空气中随机浮尘；只在侧逆光或可见光束等合理条件下少量出现 |
| `fingerprints on surface` | 表面指纹；可用于经常触碰的玻璃、金属等局部表面 |
| `organic imperfections` | 自然形成的不规则细节；落实为具体材质差异，如木纹、叶片或织物的不均匀性 |

## 7. 具体操作：主体 + 随机环境细节 + 光影缺陷 + 摄影介质词

组合公式：

> **主体 + 随机环境细节 + 光影缺陷 + 摄影介质词**

执行顺序：

1. 主体：先用真人参考锁定身份，再写服装、动作瞬间和情绪触发原因。
2. 随机环境细节：选择 1—2 个与地点用途相符的物件或状态，写清位置与材质。
3. 光影缺陷：根据现场光源挑选相容的轻微变化，注明出现区域与强度。
4. 摄影介质词：明确手机、数码相机或胶片方向，再选择相应的对焦、噪点或光学表现。

词库统一按第 1 节的强度原则调用：每张优先 2—3 项轻微不完美，总量包含皮肤、服饰、环境和成像变化；不是每个分类各叠加 2—3 项。光线、材质、构图、情绪、动作五个维度仍需写清。随机细节必须有场景依据。

用户提供的组合示例（词汇示意）：

```text
A tired barista in a small cafe, cluttered background, realistic skin pores, messy hair, harsh fluorescent lighting, shot on 35mm lens, film grain, chromatic aberration, minor imperfections.
```

此例用于展示词汇如何组合；实际生成时依据场景删选，不默认全量套用。`35mm lens` 指镜头焦距表述；若指定胶片介质，应另写 `shot on 35mm film`。

SIDE 日常照片执行示例：

```text
Use an authorized subject reference for consistent facial proportions. He has just turned toward his companion in a neighborhood bookstore, responding with a relaxed half-smile. A few books are stacked unevenly beside the shelf. Daylight from the window mixes gently with a warm reading lamp, producing a slight local color imbalance. His cotton sleeve creases naturally at the bent elbow. A casual phone photograph from the companion's eye level, slightly off-center framing, readable background, face in clear focus. Preserve existing skin texture and coherent hand anatomy.
```

该例从环境、光色和服饰中选取轻微变化；其他场景可按需替换为眩光、动态模糊或高感噪点。

## 人物一致性

- 真人参考作为身份依据，生成旧图作为场景和穿搭依据；不要仅靠反复编辑生成脸来维持身份。
- 保留脸型、五官关系、发色、年龄感和真实身材比例。自然表情可以改变，但不能变成另一张通用模特脸。
- 在提示中明确每张参考图的用途：身份参考、氛围参考或编辑目标；不要把氛围参考人物的长相混入目标人物。

## 默认提示结构

> 以真人参考锁定人物身份，指定本次场景和需要保留的服装。人物因为【具体事件】正在【动作中的瞬间】，表现出【轻微自然表情】。光来自【方向与光源】，在脸、衣服和环境上产生一致的明暗关系。【材质细节】随动作产生合理变化。由【拍摄者位置与设备】拍摄，采用【适度不完美机位】。加入【2—3 项轻微不完美】和【1—2 个相容随机状态】。保持脸部可辨、手部和配件结构合理。环境正常、空间关系成立，避免僵硬摆拍、磨皮、厚重滤镜和刻意脏旧。

## 与「氛围1」的关系

「氛围1」仍保留柔和自然光、低饱和奶油/灰蓝/浅绿色调、适度柔和成像、清爽的日常生活气质。本规范是所有照片的共同基础；其他氛围可以改变色调和场景，但同样需要人物与空间合理、瞬间自然。

## 本轮确认的测试方式

- 阅读室：听到对面说话，转头笑到一半；手从脸侧放下，卷袖高度不完全一致，窗光形成自然明暗，简化装饰背景。
- 地铁：听到同行者叫他，转头准备回应并摘下耳机；抬手处有轻微运动软化，牛仔袖肘起褶，肩带压住衣服，保留灰蓝色调与普通车厢环境。
- 用户对地铁测试表示「很好」，随后要求记录方法并应用于未来所有生成照片。此确认针对视觉方向，不代表之后的图片免于检查。

## 每次交付前检查

- 是否仍像真人参考中的本人？有没有无意美化或改变五官？
- 表情与动作是否由同一件事引起，而不是摆拍动作的机械组合？
- 手指、耳机线、肩带、倒影、窗框等结构是否成立？
- 光线和材质是否一致，背景是否有重复、漂浮或不合理透视？
- 不完美是否适量，照片是否仍然清爽且能看清本人？
- 光学缺陷是否有对应光源、运动或摄影介质依据？是否重复叠加色差、彩边、颗粒与噪点？
- 随机环境细节是否符合场所用途？胶片色调是否符合本次风格要求？
- 如需修正，针对具体问题单独调整；不通过全图加噪或变脏掩盖结构错误。

用途表述：这些仍是 AI 生成或编辑的视觉素材，真实感处理不改变素材来源，不把虚构场景描述为已经发生的服务记录或客户见证。
